为什么我要同时打两份工：双轨道人生的实践笔记

全职 + 自由职业并行一年的复盘：时间分配、心理状态、收入结构、可持续性。

打两份工一年了。复盘一下，给同样想走这条路的人参考。

为什么打两份工

  • 分散风险：一个被裁，另一个兜底
  • 覆盖更多技能：本职之外还能练设计 / 写作
  • 天花板更高：单一收入有上限
  • 满足感多元：不是只服务一家公司

时间分配

时段内容
9-18全职工作
19-21副业项目
21-23自由时间 / 学习
23-24阅读

周末主要给副业。

心理状态

第一个月：新鲜感强 第三个月：开始累 第六个月：找到节奏 第十二个月：成为习惯

关键是不跟自己较劲。累了就休息，状态好就冲。

收入结构

  • 全职：稳定的”基本盘”（覆盖房租 + 日常）
  • 副业：变动收入（储蓄 + 投资）

副业不稳定，但期望值比单一全职高。

可持续性

1. 不能 996 + 996

绝对不要两段都高强度。至少有一份是灵活的。

2. 工具要到位

  • 任务管理：Notion / Todoist
  • 自动化：n8n / Zapier
  • 财务：随手记 / Money Pro

3. 不要透支信用

两份工都要合法合规。跟公司说清楚，避免合规风险。

4. 留 buffer

体力 buffer、时间 buffer、情绪 buffer —— 三样都不能压到底。

谁适合

  • 时间管理能力强
  • 自驱力强
  • 接受延迟满足
  • 不需要每天见人的工作模式

谁不适合

  • 已经在一份工作中精疲力竭
  • 副业方向不清
  • 身体健康有问题

长远

不要把双轨当”永远的状态”。

它是一个过渡：

  • 攒经验 → 副业变主业
  • 攒资金 → 投资 / 创业
  • 攒技能 → 下一份全职的跳板

两年内必须有至少一个方向收尾。

双轨是杠杆，能撬动资源；但杠杆断了会伤人。想清楚再上。
