写文章经常需要一张好看的背景图。但每次都 PS 太麻烦，于是做了这个工具。

## 它能做什么

- 调整色相、饱和度、明度
- 选 2-5 种颜色
- 实时预览
- 一键复制 CSS

## 怎么用

1. 打开工具页面
2. 拖动色相/饱和度/明度滑块
3. 实时看预览
4. 点"复制 CSS"
5. 粘到你的代码里

## 技术栈

- HTML
- CSS
- 纯 JavaScript（无依赖）

## 为什么做这个

- **省时间**：写文章不用每次都做背景
- **风格统一**：同一个工具出来的图风格一致
- **可定制**：颜色自己调，不是固定的模板
