2026 年开始，我实践"双轨道"生活方式。本文复盘整套系统。

## 双轨道定义

- **主轨道**：全职工作（收入稳定、保险、社保）
- **副轨道**：自由职业 / 创作 / 投资（兴趣 + 长期价值）

不是"打工 + 加班"，是**两条并行的职业**。

## 一周时间表

| 时段 | 内容 |
|---|---|
| 06:30 | 起床，喝水 |
| 07:00 | 早餐 + 看新闻 |
| 08:00 | 主轨道工作开始 |
| 12:00 | 午餐 |
| 13:00 | 主轨道工作 |
| 17:00 | 主轨道结束，切换 |
| 17:30 | 健身 / 散步 |
| 18:30 | 晚餐 |
| 19:30 | 副轨道工作（90 分钟深度） |
| 21:00 | 阅读 / 学习 |
| 22:30 | 洗漱 |
| 23:00 | 睡觉 |

周末主轨道休息，副轨道深度工作。

## 工具栈

### 工作管理

- **Notion**：知识库、项目管理、日志
- **Todoist**：任务列表
- **Google Calendar**：时间块

### 副轨道

- **GitHub**：代码项目
- **Notion**：写作
- **Figma**：设计

### 财务管理

- **Money Pro**：收支记录
- **雪球**：投资跟踪

### 学习

- **Anki**：间隔重复
- **Readwise**：高亮管理
- **Obsidian**：知识图谱

## 心流时段

每天 1 段 90 分钟深度工作。**主轨道 + 副轨道各 1 段**。

90 分钟做完 1-2 件"重要的事"。

## 财务结构

| 来源 | 占比 |
|---|---|
| 主轨道工资 | 60% |
| 副轨道收入 | 25% |
| 投资收益 | 15% |

副轨道收入**不稳定但期望值高**。

## 心态管理

### 1. 不跟自己较劲

累就休息。**休息不是浪费时间，是恢复能力**。

### 2. 接受"足够好"

不是每件事都做到 100 分。**80/100 长期做 > 100/100 三天就停**。

### 3. 关注长期

短期看不到效果。**3 年后看**。

### 4. 跟合适的人在一起

不是"认识更多人"，是**深度关系**。

5 个真朋友 > 500 个赞。

## 月度复盘

每月最后一天：

1. **本月完成什么**？
2. **没完成的及为什么**？
3. **下月最重要 3 件事**？

## 季度大复盘

每季度：

1. 目标进展如何？
2. **哪些事该停止**？
3. **哪些事该开始**？
4. 长期方向是否需要调整？

## 风险管理

### 1. 健康风险

不熬夜。**身体是基础**。

### 2. 合规风险

跟公司说清楚副业。**合规**优先于"省事"。

### 3. 收入风险

副业至少 3-6 个月 buffer。**不裸奔**。

### 4. 心理风险

定期跟朋友深聊。**不闷着**。

## 给也想走双轨的人

### 1. 先有主轨道稳定

主轨道不稳，副轨道也是空中楼阁。

### 2. 副轨道要有清晰方向

不是"什么赚钱做什么"，是**有积累的方向**。

### 3. 第一年别期待收入

副轨道**第一年是投入期**，不是产出期。

### 4. 长期看，至少一个方向要收尾

3-5 年内，**主轨道升级** OR **副轨道转正**。

## 一句话

> **双轨道是杠杆，能撬动资源；但断了会伤人。想清楚再上。**

我选了双轨道 3 年了。**回不去单一轨道了**。
