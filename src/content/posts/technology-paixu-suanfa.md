排序是算法课的入门。本文梳理常见排序算法的特性。

## 对比表

| 算法 | 时间复杂度 | 空间 | 稳定性 |
|---|---|---|---|
| 冒泡 | O(n²) | O(1) | ✓ |
| 选择 | O(n²) | O(1) | ✗ |
| 插入 | O(n²) | O(1) | ✓ |
| 归并 | O(n log n) | O(n) | ✓ |
| 快速 | O(n log n) avg | O(log n) | ✗ |
| 堆排 | O(n log n) | O(1) | ✗ |

## 选择指南

- **数据少 (< 50)**：插入排序最快
- **数据大**：快排（最常用）
- **要求稳定**：归并排序
- **内存敏感**：堆排

## 实战

实际工作里，几乎不用自己写排序。语言内置的 sort 都是 O(n log n)。

但**理解原理**能帮你理解复杂度分析、时间空间权衡 — 这些在所有算法题里都通用。

## 一句话总结

> 大多数情况下用库；理解原理是为了面试 + 写自己的库。

刷题时从插入排序、快排、归并这三个开始 — 覆盖 80% 场景。
