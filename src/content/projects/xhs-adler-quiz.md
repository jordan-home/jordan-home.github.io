# 阿德勒自卑感测评

## 这是什么

基于阿德勒个体心理学理论的自助测评工具。测试通过后，你会得到：

- 主导应对模式（逃避型 / 补偿型 / 攻击型 / 接纳型）
- 四个维度的得分雷达图
- 针对性的行为改善建议

## 心理学背景

阿德勒认为，自卑感是人类进步的动力。每个人面对自卑时都会发展出特定的应对策略，有的逃避、有的过度补偿、有的攻击他人、有的学会接纳。这个工具帮你识别自己最常用的模式。

## 技术实现

- **状态管理**：Composition API 集中管理答题状态
- **结果算法**：加权计分 + 模式判定逻辑
- **动画反馈**：分数渐增动画 + 卡片翻转效果
- **无障碍**：键盘导航 + 屏幕阅读器友好
