UUSKINS 是面向全球 CS2 玩家的皮肤 P2P 交易市场。作为技术负责人，我负责日订单 10,000+ 高流量电商平台的前端架构与工程体系。

我的角色

技术负责人。独立主导 Next.js SSR 架构升级、国际化体系、跨境支付、全链路监控，覆盖从需求到上线的完整技术决策链。

业务背景

CS2 皮肤市场规模数十亿美金，但主流平台（Buff、CSFloat）有两大痛点：

  1. 卖家挂单繁琐：要装 Steam 客户端、配置 API key、跑长链路
  2. 买家交付慢：行业平均 1-2 小时，长得让人以为被骗

UUSKINS 解决方案：

  • 0 押金租赁：降低玩家试用门槛
  • P2P 卖家端：可视化引导，普通玩家 5 分钟能挂单
  • 10 分钟自动交付：把交易确认 / Steam 通知 / 库存转移做成自动流水线

我的工作

  • SSR 架构升级：主导 Next.js App Router 迁移，实现服务端渲染 + 客户端水合，提升 SEO 与自然搜索流量
  • 国际化体系：基于 next-intl 搭建自动化翻译流水线，支持 SEO 友好的多语言 Slug 路由
  • 跨境支付全链路：多币种汇率换算、Visa/Mastercard/本地支付渠道接入、自助 KYC 持卡人验证
  • 全链路监控：OpenTelemetry + 阿里云 ARMS RUM，覆盖接口请求、订单转化、CSP 安全策略
  • 灰度发布系统：构建 canary 灰度发布 + feature flags，部署事故降低 40%
  • 组件体系：主导组件复用与设计一致性建设，沉淀可复用组件与主题定制方案
  • AI 协作工作流：Cursor 生成代码 + 人工 Review，覆盖代码生成、单元测试、规范校验全流程

当前状态

2025 年上线，2026 年运营中。Trustpilot 4.3/5.0 评分（基于数百条评价）。

前端专项

  • 架构设计：Next.js SSR + WebSocket 实时库存更新，React Query 服务端状态管理，交易状态机（Pending → Confirmed → Delivered）
  • 性能优化：虚拟列表处理大规模 SKU 渲染，IntersectionObserver 滚动加载，首屏响应迅速；Web Workers 处理价格计算
  • 类型安全：TypeScript 严格模式 + 全量类型检查，WebSocket 消息类型定义（SteamTrade / PaymentConfirm / InventoryUpdate）
  • 工程规范：灰度发布 + feature flags 控制功能上线节奏，Jest + React Testing Library，Mock Service Worker 拦截 Steam API，CI 覆盖 build + lint + test
