PetMona 是一个面向北美宠物主人市场的 AI 肖像生成电商。

解决的问题

把宠物照片转成『能挂上墙』的艺术品。市场上同类产品订阅制复杂、AI 生成的图常常『不像』，价格也不透明。

我的工作

独立从 0 到 1 交付：需求调研 → 技术选型 → AI 生成流水线设计 → 全栈开发 → Stripe 支付集成 → Artelo 印刷对接 → 上线运营 → 持续迭代。全流程独立决策、编码、维护。

设计原则

无订阅、无月费。上传照片 → 免费预览（每邮箱 + 设备 3 次）→ 满意才付费解锁高清。为纪念场景（临终宠物 / 彩虹桥）专门设计了温和风格系列——情绪价值是这个产品的核心。

技术实现

  • AI 生成流水线：fal.ai Flux Kontext（图生图）为主力，Agnes AI 失败自动兜底（DEFAULT_PROVIDER_ORDER = fal, agnes）
  • 支付：Stripe 多 SKU（$3.99 单张解锁 / $12.99 五张打包 / $36.99 8×10 印刷 / $79 12×16 黑橡木裱框）
  • 实体印刷：Artelo 自动履约（美国本土印刷 + 全球物流）
  • 国际化：next-intl 6 语言（en/es/de/fr/pt-BR/it），en 无前缀 + 其他语言前缀路由

当前状态

2026 年初上线，重点投放 Reddit 宠物社区 + Instagram。

前端专项

  • 架构设计：Next.js 15 App Router + next-intl i18n 路由，Dynamic Import 按需加载 AI 生成模块，Vercel Blob 存图 + KV 存任务状态
  • 性能优化：Lighthouse 84/100（本地实测）；图片懒加载 + 自适应格式，生成结果 CDN 分发
  • 类型安全：TypeScript 严格模式 + 全量类型检查，状态管理类型推导（预览 / 订单 / 风格选择）
  • 工程规范：Vitest 单元测试（支付流程 / 图片处理 / 额度逻辑），ESLint，GitHub Actions CI
