SweetNovel 是一个面向英文读者的独立甜系言情网文站，主打『免费试读 + 订阅解锁』模式。

我的角色

独立从 0 到 1 交付：需求调研 → 技术选型 → 架构设计 → 全栈开发 → 部署上线 → SEO 体系 → 持续运营迭代。全流程独立决策、编码、维护。

我做的事

  • 作品库 + 阅读器：23 部原创长篇（M/M、M/F、F/F 多性向），基于 Markdown 内容管线的长文排版
  • 付费墙设计：免费试读章节引流到 Patreon 订阅（$5.50/月）；另设 PayPal 单本买断 $3.99，拦截『只想看一本』的流失读者
  • 账号体系：Clerk 登录 + 月度口令 VIP 解锁双通道
  • SEO 体系：sitemap / robots / llms.txt / OG 图自动生成，GA4 转化跟踪（book_purchase_success 等自定义事件）
  • 内容生产管线：AI 辅助翻译 + 编辑校对，配合自动化的章节发布、新章推送（Web Push）

为什么做这个

英文市场对甜系言情网文的需求真实存在，但主流平台几乎都是『先注册 / 先买币 / 看完结』——拦住了大部分潜在读者。『免费试读 + 订阅引导』打开了这条路。

数据

2026 年上线，SEO 优化带来每周稳定自然搜索会话（简历口径：每周 64 次），GA4 全链路转化跟踪已部署。

前端专项

  • 架构设计：Next.js App Router，route-based 代码分割（browse/series/book 各自独立 chunk），Supabase 服务端组件代理
  • 性能优化：Lighthouse 78/100（本地实测）；静态内容 CDN 缓存，图片懒加载 + 自适应格式
  • 类型安全：TypeScript 严格模式 + 全量类型检查，泛型组件（ArticleCard / BookGrid / ChapterList / TagFilter）
  • 工程规范：ESLint + Prettier，Husky pre-commit hook，内容 schema 校验 + 链接检查流水线（check:content）
